# task-015 — 웹 브라우저 모드 (주석 · PC/모바일 · 콘솔 에러 → 에이전트 채팅)

## 상태
- 생성일: 2026-09-27
- 요청: "브라우저에 주석을 넣고 채팅하면 주석 위치를 인식해 문제를 파악", "가운데 브라우저 / 오른쪽 에이전트 터미널 채팅", "PC·모바일 보기", "콘솔 에러 파악"
- 우선순위: P1

## 설계
| 항목 | 결정 | 이유 |
|---|---|---|
| 브라우저 엔진 | Electron `BrowserView` (Electron 27) | 실제 Chromium, 앱 렌더러와 프로세스 분리. `<webview>`는 보안상 꺼 둠 |
| 격리 | 별도 **메모리 세션**(`cc-browser`, 비영구), sandbox, preload 없음, 권한 요청·다운로드 거부, http(s)만 | 로드한 사이트가 앱 IPC에 닿지 않게, 종료 시 쿠키·캐시가 남지 않게 |
| 레이아웃 | 사이드바 │ 브라우저(가운데, flex) │ 터미널+입력창(오른쪽 40%) | 요청 그대로 |
| 모바일 | CDP `Emulation.setDeviceMetricsOverride`(390×844, DPR 3, mobile) + 모바일 UA + 터치 | 반응형 CSS·미디어쿼리가 실제 모바일처럼 동작 |
| 주석 | 격리된 JS 월드(999)에 오버레이 주입 → 요소 위 하이라이트, 클릭 시 번호 핀 + selector·태그·텍스트·위치 반환 | 페이지 스크립트와 변수 공유 안 함, 앱 IPC 노출 없음 |
| 채팅 연동 | 입력창 전송 시 [브라우저 컨텍스트] 블록을 앞에 붙임: URL·기기·핀 목록·핀이 그려진 스크린샷 경로·최근 콘솔 에러 | 어떤 CLI(claude/codex)든 텍스트+이미지 경로로 이해 |
| 콘솔 에러 | `console-message`(error), 페이지 로드 실패, 렌더러 크래시 → 최근 100건 링버퍼, 배지·목록, 마지막 전송 이후 것만 첨부(최대 8건) | 반복 첨부 방지 |
| 저장 | 스크린샷은 **앱 데이터 폴더** `<userData>/browser-shots/`, 최근 20장·3일 초과 삭제. 프로젝트 폴더에는 아무것도 쓰지 않음 (r3에서 변경: 프로젝트 경로는 junction 경쟁을 원자적으로 막을 수 없음) | 보안 + "데이터 많이 남기지 말자" |
| 셸 보호 | 컨텍스트는 에이전트 CLI + bracketed paste 페인에만, main이 쓰기 순간 PTY 출력으로 추적한 bracketed 상태를 재확인(`pty:paste-guarded`), 모든 컨텍스트 줄은 `# `로 시작(셸이 받아도 주석) | 페이지 문자열의 명령 실행 방지 |

## 검증 계획
- 로컬 테스트 서버 페이지(콘솔 에러·버튼) 로드 → 에러 수집, 모바일 전환 시 `innerWidth=390`, 주석 클릭 → 핀·selector, 입력창 전송 → 터미널에 컨텍스트 + 스크린샷 파일 존재, 모달 열면 브라우저 숨김, URL 검증(javascript:/file: 거부)

## 구현 결과
- `main-browser.js`(BrowserView·격리 세션·CDP 모바일 에뮬레이션·격리 월드 주석 오버레이·콘솔/네트워크/크래시 에러·캡처 저장/정리), `renderer-browser.js`(툴바·레이아웃 3:2·주석 루프·콘솔 패널·`decorate()`), 입력창 전송 경로에 연결
- 수정한 문제: 처음 연 뷰에서 CDP 명령이 멈춰 `browser:open`이 응답하지 않음 → 먼저 이동, PC는 debugger 미사용, 모든 CDP·로드에 타임아웃. 404 등 네트워크 실패는 console-message로 오지 않음 → `webRequest`로 수집
- `npm run test:browser` 24/24 (2회 연속): 레이아웃, javascript: 거부, 페이지에서 앱 브리지 안 보임, 에러 수집·패널, 모바일 innerWidth 390·UA·터치, 주석 핀·selector·페이지 핸들러 미실행, 채팅에 컨텍스트·캡처 파일(앱 데이터 폴더), 보낸 뒤 핀/새 에러 정리, 닫을 때 뷰 제거
- 미검증: 모달이 열릴 때 뷰 숨김(코드 경로만), 실제 Claude Code가 캡처 이미지를 읽는 동작
