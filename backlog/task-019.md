# task-019 — 콘솔 에러를 버튼으로 채팅 입력창에

## 요청
"새 콘솔 에러를 채팅에 첨부" 부분이 체크박스라 버튼이 없음 → 클릭하면 채팅창(입력창)에 들어가게.

## 변경
- 체크박스(`#br-include-errors`, 보낼 때 자동 첨부) → 버튼 `#br-errors-to-chat` "⚠ 새 콘솔 에러 N건 → 채팅에 넣기" (새 에러 없으면 비활성)
- 클릭: 마지막 전송 이후의 새 에러(최대 8건 + 생략 건수)를 입력창에 이어 붙임 — 보내기 전에 보고 고칠 수 있음. 두 번 눌러도 한 번만
- 자동 첨부는 없앰(같은 에러 중복 방지). 에러는 버튼으로 넣은 블록으로만 전달
- 보호 유지(review C3): 넣은 줄은 모두 `# ` 주석이고 main에서 제어문자·줄바꿈이 이미 제거됨. 그 블록이 입력 내용에 남아 있으면 주석과 같은 경로(에이전트 페인 전용, guarded paste)로만 전송, 일반 셸이면 거부하고 입력 내용 유지
- "보냄" 처리는 실제 전달된 뒤에만, 넣은 시점까지의 에러만 (그 뒤 에러는 계속 새 에러)
