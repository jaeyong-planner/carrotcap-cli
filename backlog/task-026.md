# task-026 — ⚙ 설정 패널(좌측 상단) · 다크/화이트 테마

## 요청 (2026-09-28)
검은 배경뿐 아니라 화이트 배경에 어울리는 터미널 폰트·색 구조로, 화면을 검정/화이트 2벌 중 취향대로 고를 수 있게.
좌측 상단에 설정 버튼을 두고 나머지 설정도 그곳으로 옮김 → 사용자 선택: **설정·토글만 이동** (작업 버튼은 사이드바에 둠)

## 설계
- 좌측 상단 ⚙ → 설정 패널: 화면 테마(다크 / 화이트 / 시스템), 터미널 글꼴 크기(8~32), 모드(AOR·AIOps), 보기(브라우저·입력창), 파일(AOR 규칙 편집 · 🔑 API 키)
  - 기존 요소를 id 그대로 옮김(탭 바의 브라우저·입력창·AOR, 사이드바 MODE, AI DEV FLOW의 API 키) → 기존 동작·테스트 유지
  - Esc·바깥 클릭으로 닫힘, `aria-expanded`/`aria-pressed`
- 테마: `:root[data-theme="light"]`에서 같은 역할의 토큰만 바꿈. 흰 배경 / --panel 기준 글자 대비 WCAG AA(4.5:1) 이상 실측
- 터미널: 다크·화이트용 ANSI 팔레트 따로. 화이트에서는 CLI가 쓰는 "white/bright" 글자를 읽을 수 있는 회색으로, `drawBoldTextInBrightColors: false`(굵은 글씨가 더 옅어지지 않게), `minimumContrastRatio: 4.5`(프로그램이 직접 고른 색도 대비 보정). 모든 색이 흰 배경 대비 4.93~15.8:1
- 바꾸면 열려 있는 터미널에 바로 적용하고 `settings.json` `ui.theme`·`ui.fontSize`에 저장. main은 이 두 값만 받음(글꼴 이름·CLI 등은 디스크 값 유지)
- 창 배경색(그리기 전 번쩍임)과 네이티브 위젯(스크롤바)도 테마를 따름(`nativeTheme.themeSource`)
- 시스템: Windows 다크/라이트 설정을 따르고, 바뀌면 바로 반영
